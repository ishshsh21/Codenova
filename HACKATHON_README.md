# Workday Signal

Workday Signal is a Gmail AI Workday Agent that turns inbox messages into a clear, prioritized work plan.

## Features

- Secure Gmail OAuth connection with read-only access
- Configurable Gmail scanning date range
- AI-powered email classification and task extraction
- Automatic task titles, deadlines, priority, effort estimates, owners, projects, and confidence signals
- Today dashboard for actionable, critical, due-today, overdue, and weekly work
- Timestamp-based overdue and due-today classification
- Focus-next recommendations and daily workload estimate
- Search and priority filters
- Weekly planning view with daily task cards, calendar, KPI filters, and undated tasks
- Task detail panel with source context, editing, completion, dismissal, and snoozing
- Scan history, progress tracking, and notifications
- User settings for work hours, timezone, scan defaults, VIP senders, and ignored senders
- AI Assistant with quick actions, conversation history, task-context answers, and supported task actions
- Responsive dark-mode interface

## Hackathon Demo Script

Hi everyone, this is Workday Signal — a Gmail AI Workday Agent that turns inbox noise into a clear action plan.

Students and professionals receive important tasks through email, but those tasks are often buried between newsletters, announcements, meeting invitations, and follow-ups. Workday Signal solves that problem.

First, I connect Gmail using secure read-only authentication. The app scans a selected date range and uses AI to classify emails, identify actionable work, extract deadlines, estimate effort, and assign priority.

Instead of manually reading every email, I immediately get a dashboard showing what is actionable, critical, due today, overdue, and planned for this week.

For example, this task is marked high priority because it has a near deadline and remains open. I can open it to view its source context, priority explanation, and task details. From here, I can complete it, snooze it, edit its deadline, or dismiss it.

The Today view answers the key question: “What should I do next?” It provides focus tasks and an estimated workload for the day.

The This Week view organizes tasks by day, highlights high-priority work, and places undated tasks in a Later section. This makes planning easier without changing the original Gmail data.

We also added an AI Assistant. I can ask questions such as “What’s urgent today?”, “Show my pending tasks”, or “Why is this task high priority?” The assistant uses existing Workday Signal task context instead of inventing information.

I can also take supported actions conversationally. For example: “Mark Submit assignment as completed,” “Make this task high priority,” or “Move this task to tomorrow.”

Workday Signal gives users one clear view of their workday: less inbox overload, better prioritization, and faster action.

Thank you.
